## CPU or GPU?

The CPU and GPU use silacon and contain millions of transistors, but they are very
diffrent in the way that they process data. when creating GLSL shaders we are working with Parallel Processing

# Parallel Processing
this means if we paint this pixel it knows nothing about the choice of color for the pixel to the right, left, above or below
because they are being calculated at the same time
